# /check — быстрая проверка перед коммитом

## Шаг 1 — синтаксис изменённых .py-файлов

```bash
git diff HEAD --name-only --diff-filter=ACMR -- '*.py'
```
Для каждого файла из списка:
```bash
python3 -m py_compile <файл>
```
Если `py_compile` ругается — показать ошибку как есть, не чинить
самостоятельно.

## Шаг 2 — ревью диффа сабагентом reviewer

```bash
git diff HEAD
```
Если дифф пустой — сказать «нечего проверять» и перейти к шагу 3.

Иначе вызвать Agent (subagent_type: "reviewer"), вставив в промпт
текст диффа из `git diff HEAD` целиком и попросив проверить именно эти
изменения на баги и краевые случаи. У reviewer нет доступа к Bash —
дифф нужно передать текстом в промпте, сам он его не получит.

## Шаг 3 — git status

```bash
git status -sb
```
Показать как есть.

## Итог

Показать пользователю все три результата подряд: синтаксис (порядок
или ошибки) / находки reviewer (или «дифф пуст») / вывод git status.
