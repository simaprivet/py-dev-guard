# /push-review — ревью диффа перед пушем

Запустить:

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/push_review.py
```

Показать пользователю вывод скрипта как есть — ни расширять, ни
интерпретировать, ни переформулировать. Скрипт сам:

- собирает дифф текущей ветки относительно `master`;
- если диффа нет (ветка не отличается от `master`) — печатает об этом и
  завершается без обращения к модели;
- если диффа слишком много — отказывается ревьюить и просит сузить
  диапазон, вместо того чтобы обрезать часть изменений;
- если `claude` не найден в PATH — печатает об этом, а не падает
  трейсбеком;
- иначе отправляет дифф на ревью отдельным вызовом `claude -p
  --output-format json` (не через Agent/сабагента — вызов внешний,
  как из скрипта или CI) и печатает разобранный ответ.

Ревью ищет только логические ошибки и краевые случаи, забытый
отладочный код, секреты/ключи и очевидные проблемы безопасности
(конкатенация в SQL, небезопасная работа с путями). Стиль вне зоны
внимания. Ничего не правится — только замечания в терминал. Не
пытайся сам исправлять код по итогам ревью, если пользователь явно не
попросит.
